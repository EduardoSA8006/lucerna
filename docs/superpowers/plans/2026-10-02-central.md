# Central em quatro painéis — plano de implementação

> **Para agentes:** SUB-SKILL OBRIGATÓRIO: use superpowers:subagent-driven-development (recomendado) ou superpowers:executing-plans para implementar este plano tarefa por tarefa. Os passos usam checkbox (`- [ ]`) para acompanhamento.

**Objetivo:** trocar a barra lateral (`features/sidebar/`) pela central: quatro painéis flutuantes e minimalistas que abrem e fecham juntos, som e energia à esquerda, controles e notificações à direita, com a entrada (ícone da barra, atalho, launcher ou IPC) escolhendo o que já vem aberto.

**Arquitetura:** a entrada da central fica no `Panels` (`core/`, coberto pelo gate): `centralEntry`, `openCentral`, `toggleCentral` e o sinal `centralOpened`. A feature `features/sidebar/` é movida inteira (`git mv`) para `features/central/` na Tarefa 2, e a barra lateral antiga convive com a central dentro da mesma feature até a Tarefa 6: cada tarefa de painel tira da barra lateral a seção que o painel novo substitui e troca as entradas dela (ícone da barra, launcher). O `CentralState` guarda as páginas abertas nos cards (`controlsPage`, `soundPage`), que a entrada define e o fechamento zera. Os volumes por app vêm de um serviço novo, `services/AudioStreams.qml`, com a montagem da lista numa função pura coberta pelo gate. A tela é um `OverlayPanel` modal com `dim: 0`, com os quatro painéis como filhos diretos (o clique fora de todos fecha) e uma moldura comum, `CentralPanel`, que faz a entrada em cascata.

**Tecnologia:** Quickshell 0.3.1 (QML/Qt 6; `Quickshell.Services.Pipewire`, `Quickshell.Services.UPower`, `Quickshell.Bluetooth`, `Quickshell.Networking`), Hyprland 0.56 com config em Lua, harness `tests/runner.qml` no `qs`, `dev/ci.sh` (lint, rules, unit, smoke no `archlinux:latest`) e `dev/test.sh` (conferência visual no container `lucerna-polish`, capturas em 1920×1080).

**Spec:** `docs/superpowers/specs/2026-10-02-central-design.md` (leia inteiro antes da primeira tarefa; este plano argumenta a partir dele). O rascunho visual aprovado é o `quatro-paineis-v2.html` da conversa de desenho; as medidas dele já estão traduzidas em tokens na seção "Visual" abaixo.

## Global Constraints

- Quatro painéis, um assunto cada: **Som** (esquerda, em cima), **Energia** (esquerda, embaixo), **Controles** (direita, em cima) e **Notificações** (direita, embaixo, na altura que sobra, rolando).
- Abrem e fecham juntos, como um painel só (`central`), sobre a área de trabalho, **sem escurecer a tela**; a central é **modal**: abrir o painel superior, o launcher, as configurações etc. fecha a central, e vice-versa.
- Entradas: o atalho que hoje abre a barra lateral (`Super+C`; `Alt+C` no desenvolvimento), os ícones da direita da barra e o launcher ("Wi-Fi", "Bluetooth", "Som" e "Notificações"). Ícone de rede → card de controles na lista de redes; "Bluetooth" → lista de dispositivos; sino e `Super+N` → a central com as notificações, sem subpágina; os demais → o estado inicial.
- Fecham: clicar de novo no mesmo ícone, `Esc` e o clique fora de todos os painéis.
- IPC: `central open [rede|bluetooth|som|notificacoes|energia]`, `central toggle [...]` e `central close`. `sidebar open wifi` e os demais nomes antigos deixam de existir.
- Entrada animada: cada painel desliza do seu lado e aparece, com um pequeno atraso entre os quatro (40 ms × ordem × `ThemeManager.anim.scale`); a saída é mais rápida e de todos juntos.
- Largura de **400 px**; esquerda e direita colam nas bordas com a mesma margem, abaixo da barra (`Panels.topInset`).
- Minimalistas: sem títulos, legendas e informações óbvias; as porcentagens ficam: **em cada volume** (saída, entrada e cada app), **no brilho** e na bateria.
- Nada repete o painel superior (relógio, calendário, clima, mídia e desempenho ficam só nele).
- Saem do shell o consumo (W) e a saúde da bateria. Vão para as Configurações o brilho de cada monitor e a temperatura da luz noturna (esta já está em Configurações → Luz noturna).
- Saem `sidebarSide`, a página "Central lateral" das Configurações e o recuo do painel superior (`leftInset`/`rightInset`, e com ele `panelsAvoidOverlap`).
- Fora do escopo: a dock, modo avião e histórico persistente de notificações.
- Camadas (`ci/rules.py`): `core/` não importa `qs.features` nem `qs.services`; `features/*/ui` não importa `qs.services`; uma feature não importa outra.
- Lint com `MaxWarnings=0`: `pragma ComponentBehavior: Bound` com `required property` nos delegates e ids qualificados; nenhum import sem uso; nenhuma supressão do qmllint além das três registradas.
- O lint só analisa o que o `shell.qml` alcança pelos imports: toda pasta nova de QML precisa ser importada por algo que o shell importa **na mesma tarefa** (senão "Faltam na árvore").
- Estilo compacto da casa (`Behavior on x { Anim { type: Anim.Spatial } }` numa linha); nada de `qmlformat`.
- Funções do escopo de cobertura declaradas como `function nome(...) {` numa linha; 100% delas chamadas pelos testes.
- Testes: prefira `t.eq`; `t.check(a === b)` só para identidade; restaure `Config`, `Battery` e `Panels.opened` no fim de cada caso; nada de hora real nem espera real.
- Regras sempre por `dev/ci.sh rules` (no container do CI), não por `python3 ci/rules.py` no host.
- Tudo em português do Brasil com acentos: textos da interface, comentários, documentação e mensagens de commit.
- Conferência visual só no `lucerna-polish` (`dev/test.sh`); nunca mexer no container `lucerna-dev`. As teclas vão por `dev/test.sh run 'wtype ...'`; os cliques com o mouse ficam para o usuário.

## Decisões

- **A central é modal sobre uma camada de tela inteira** (`OverlayPanel` com `dim: 0`, como o seletor de temas). A barra fica visível embaixo, mas o clique nela cai na camada da central: é um clique fora e fecha. Isso cumpre o "clicar de novo no mesmo ícone fecha"; um clique num ícone diferente também só fecha, e o segundo clique abre na entrada nova. A troca de entrada com a central aberta existe pelo IPC e pelos atalhos (`Super+N` com a central aberta pelo `Super+C` troca para as notificações).
- **Entrada no `Panels`** (`core/`, no gate): `centralEntries`, `centralEntry`, `signal centralOpened(string entry)`, `openCentral(entry)` e `toggleCentral(entry)`. Entrada desconhecida vale como `""`. O `toggleCentral` fecha quando a central está aberta e a entrada pedida é a mesma **ou** é a vazia (o atalho `Super+C` fecha de qualquer entrada); senão abre ou troca. A central fechada zera a entrada (`onOpenedChanged`), então `panels open central` abre no estado inicial.
- **Páginas no `CentralState`**: `controlsPage` (`""`, `"wifi"` ou `"bluetooth"`) e `soundPage` (`""`, `"outputs"` ou `"inputs"`). Abrir e fechar zeram as duas; o `centralOpened` aplica `pageFor(entry)` (rede → `"wifi"`, bluetooth → `"bluetooth"`, o resto → `""`) e fecha a lista do som. O IPC `central` também fica no `CentralState` (fora do gate, como o antigo `sidebar`).
- **IPC sem entrada**: o IPC do Quickshell exige o argumento declarado, então "sem entrada" é `central open ""` (como o `launcher open files ""` de hoje). O README diz isso.
- **`git mv features/sidebar features/central` na Tarefa 2**, inteira: os states de Wi-Fi, Bluetooth, Som, Avisos (`InboxState`) e Bateria (`PowerState`) e os componentes `ListRow`, `EmptyState`, `WifiPage` e `BluetoothPage` ficam com o histórico. A barra lateral antiga (`Sidebar`, `SidebarState`, `Rail`, `SectionHeader` e as páginas que ainda não foram trocadas) continua funcionando dentro da feature nova até a Tarefa 6, e cada tarefa de painel tira dela a seção substituída. Assim a regra "uma feature não importa outra" nunca é ferida, e o lint acha as pastas novas desde a Tarefa 2.
- **Entradas trocadas junto com o painel**: a Tarefa 3 troca o ícone de rede da barra e "Wi-Fi"/"Bluetooth" do launcher; a 4, o ícone de volume e "Som"; a 5, o ícone de bateria; a 6, o sino, `Super+C`, `Super+N`, "Notificações" e o resto. Entre as tarefas, nenhum caminho abre uma seção que não existe mais.
- **Serviço novo `services/AudioStreams.qml`** em vez de crescer o `Audio`: `describe(nodes)` é pura (coberta pelo gate) e filtra pelo `media.class` do PipeWire igual a `"Stream/Output/Audio"` (o app que toca), que não depende da semântica do `isSink` nos streams. "Tocando agora" é o stream aberto: o `PwNode` da 0.3 não expõe se está tocando, então um player pausado com o stream aberto aparece.
- **Energia continua no `PowerState`** (o nome serve: é o view model da energia). Ganha `profilesAvailable`, `profileButtons`, `batteryNote`, `withBattery(list)` (pura) e `any`; perde o que só a página antiga usava. O fluxo é testado pelo runner (`t.PowerState`), como o `ThemeSwitcherState`.
- **"Sem perfil de energia disponível"**: o `PowerProfiles` do Quickshell não diz se o daemon existe. O `Battery` ganha `profilesAvailable`, de uma sonda `busctl --system introspect` no `net.hadess.PowerProfiles` (ou no `org.freedesktop.UPower.PowerProfiles`), por `sh -c` (no CI, sem `busctl` ou sem D-Bus do sistema, sai com erro calado, sem o aviso "Process failed to start"). Sem o perfil de desempenho, os botões são dois.
- **Som sem áudio nenhum some**, como a energia: sem saída, sem entrada e sem streams, `present: false`. O spec não diz; um painel vazio contradiz o minimalismo.
- **Linha do card de rede inteira abre a página** (ícone aceso quando conectado, título com a rede ou o estado, a legenda "Wi-Fi"/"Bluetooth" do rascunho e a setinha); o liga/desliga fica no topo da página, como diz o spec.
- **Botões de ícone somem sem o recurso**: luz noturna só com o `hyprsunset` (`NightLight.available`); "não apagar a tela" só com a ociosidade do shell ligada (`Config.idleEnabled`, como a seção Tela fazia). A grade tem sempre quatro colunas, para os botões não esticarem.
- **Brilho de cada monitor vai para Configurações → Tela e ociosidade** (seção "Brilho" no topo, pelo `IdleSettings`); a temperatura da luz noturna já está em Configurações → Luz noturna.
- **Atalho `sidebar` vira `central`** em `ShellShortcuts`, `InputActions` e `ShortcutsState`. Uma tecla personalizada salva sob `sidebar` em `Config.shellShortcuts` volta ao padrão (`Super+C`), e um botão do mouse mapeado para a ação `sidebar` deixa de fazer algo; não há migração (o shell não tem usuários além do autor; registrado na resposta ao usuário).
- **Configurações → Painéis** fica só com o painel superior em "Abrir juntos" (a central é modal); sai a seção "Posição" e o `panelsAvoidOverlap`. O `Panels.companions` aceita só `"dashboard"`; um `"sidebar"` velho no config é ignorado.
- **Popups**: com a central aberta, escondidos; abrir a central conta como tê-los visto (`clearPopups`), porque ela sempre mostra as notificações.
- **Notificações vêm junto com a moldura (Tarefa 2)**: é o painel mais simples, reaproveita o `InboxState` e o `NotificationCard`, e dá à Tarefa 2 uma tela para conferir a moldura, a posição e a cascata.

// Testes de services/AudioStreams: a lista de streams por aplicativo e o
// volume e o mudo de um stream. Os nós são objetos falsos; nenhuma
// propriedade do singleton é gravada.
function run(t) {
    const S = t.AudioStreams;

    // Um nó falso do PipeWire com a classe e as propriedades dadas.
    function node(mediaClass, props, audio, extra) {
        return Object.assign({ name: "", description: "", properties: Object.assign({ "media.class": mediaClass }, props), audio: audio }, extra ?? {});
    }

    t.test("audiostreams: só os streams de reprodução, com nome, ícone, volume e mudo", () => {
        const firefox = node("Stream/Output/Audio", { "application.name": "Firefox", "application.icon-name": "firefox" }, { volume: 0.8, muted: false });
        const spotify = node("Stream/Output/Audio", { "application.name": "Spotify", "application.icon-name": "spotify" }, { volume: 0.55, muted: true });
        const recorder = node("Stream/Input/Audio", { "application.name": "OBS" }, { volume: 1, muted: false });
        const speakers = node("Audio/Sink", {}, { volume: 0.6, muted: false }, { description: "Alto-falantes" });
        const video = node("Stream/Output/Video", { "application.name": "Câmera" }, null);
        const list = S.describe([speakers, firefox, recorder, spotify, video]);
        t.eq(list.map(s => [s.name, s.icon, s.volume, s.muted]), [["Firefox", "firefox", 0.8, false], ["Spotify", "spotify", 0.55, true]]);
        t.check(list[0].node === firefox, "o nó vem junto, para o volume e o mudo");
    });

    t.test("audiostreams: nome e ícone na falta das propriedades do app", () => {
        const list = S.describe([
            node("Stream/Output/Audio", { "media.name": "Vídeo do YouTube", "application.process.binary": "chromium" }, { volume: 1, muted: false }),
            node("Stream/Output/Audio", {}, { volume: 1, muted: false }, { description: "Saída do jogo", name: "game" }),
            node("Stream/Output/Audio", {}, { volume: 1, muted: false }, { name: "alsa_playback.aplay" }),
            node("Stream/Output/Audio", {}, { volume: 1, muted: false })
        ]);
        t.eq(list.map(s => [s.name, s.icon]), [["Vídeo do YouTube", "chromium"], ["Saída do jogo", ""], ["alsa_playback.aplay", ""], ["", ""]]);
    });

    t.test("audiostreams: nós nulos e lista vazia", () => {
        const one = node("Stream/Output/Audio", { "application.name": "mpv" }, { volume: 0.3, muted: false });
        t.eq(S.describe([null, one, undefined]).map(s => s.name), ["mpv"]);
        t.eq(S.describe([]), []);
        t.eq(S.describe(null), []);
    });

    t.test("audiostreams: volume e mudo de um stream", () => {
        const audio = { volume: 0.5, muted: true };
        const stream = node("Stream/Output/Audio", {}, audio);
        S.setVolume(stream, 1.4);
        t.eq([audio.volume, audio.muted], [1, false], "mover o volume tira o mudo e limita em 1");

        t.eq(audio.volume, 0, "limita em 0");
        S.toggleMute(stream);
        t.eq(audio.muted, true);
        S.toggleMute(stream);
        t.eq(audio.muted, false);
        S.setVolume(null, 0.5);
        S.toggleMute(node("Stream/Output/Audio", {}, null));
    });
}

import QtQuick
import Quickshell

// Áudio por aplicativo: os streams de reprodução do PipeWire (um por app com a
// saída de som aberta), com o nome e o ícone do app, o volume e o mudo. O
// `describe` é puro: monta a lista a partir dos nós.
Singleton {
    id: root

    // [{ node, name, icon, volume, muted }]
    readonly property var list: describe(Pipewire.nodes.values)

    // Só os streams de reprodução com áudio ("Stream/Output/Audio" no
    // PipeWire): gravações, dispositivos e vídeo ficam de fora. O nome e o
    // ícone vêm do app; na falta, do próprio nó.
    function describe(nodes: var): var {
        return (nodes ?? []).filter(n => n?.properties?.["media.class"] === "Stream/Output/Audio" && n.audio).map(n => {
            const p = n.properties;
            return {
                node: n,
                name: p["application.name"] || p["media.name"] || n.description || n.name || "",
                icon: p["application.icon-name"] || p["application.process.binary"] || "",
                volume: n.audio.volume ?? 0,
                muted: n.audio.muted ?? false
            };
        });
    }

    function setVolume(node: var, value: real): void {
        if (!node?.audio)
            return;
        node.audio.muted = false;
        node.audio.volume = Math.max(0, Math.min(1, value));
    }

    function toggleMute(node: var): void {
        if (node?.audio)
            node.audio.muted = !node.audio.muted;
    }

    // Sem rastrear o nó, volume e mudo não são atualizados.
    PwObjectTracker {
        objects: root.list.map(s => s.node)
    }

import QtQuick

// View model da central: os quatro painéis flutuantes (som e energia à
// esquerda, controles e notificações à direita) que abrem e fecham juntos. A
// entrada (Panels.centralEntry) escolhe o que já vem aberto: "rede" abre o
// card de controles na lista de redes; "bluetooth", nos dispositivos; as
// outras, o estado inicial. Abrir e fechar voltam tudo ao estado inicial.
Singleton {
    id: root

    readonly property bool open: Panels.isOpen("central")
    readonly property var screen: Hypr.focusedScreen
    readonly property string entry: Panels.centralEntry
    // Distância do topo da tela: abaixo da barra, como o painel superior.
    readonly property real top: Panels.topInset

    // O que o card de controles mostra ("" os controles; "wifi" ou
    // "bluetooth", a página do recurso) e o card de saída e entrada do som
    // ("" os volumes; "outputs" ou "inputs", a lista de dispositivos).
    property string controlsPage: ""
    property string soundPage: ""

    onOpenChanged: reset()

    Connections {
        target: Panels

        function onCentralOpened(entry) {
            root.controlsPage = root.pageFor(entry);
            root.soundPage = "";
        }
    }

    function pageFor(entry: string): string {
        return entry === "rede" ? "wifi" : entry === "bluetooth" ? "bluetooth" : "";
    }

    function reset(): void {
        controlsPage = "";
        soundPage = "";
    }

    function setControlsPage(page: string): void {
        controlsPage = page;
    }

    function setSoundPage(page: string): void {
        soundPage = page;
    }

    function close(): void {
        Panels.dismiss("central");
    }

    IpcHandler {
        target: "central"

        // Abre numa entrada: rede, bluetooth, som, notificacoes, energia ("" = o estado inicial).
        function open(entry: string): void {
            Panels.openCentral(entry);
        }

        function toggle(entry: string): void {
            Panels.toggleCentral(entry);
        }

        function close(): void {
            Panels.dismiss("central");
        }
    }

import QtQuick
import qs.core.theme

// Um dos quatro painéis da central: o vidro dos painéis do shell, 400 px de
// largura, colado na borda do seu lado (`leftSide`) a `margin` dela. Entra
// deslizando desse lado, com um atraso pela ordem (`order`: 40 ms por passo,
// na escala das animações), e sai junto com os outros, mais rápido.
// `present` falso esconde o painel (nada a mostrar). Os filhos vão para
// dentro da margem interna (`padding`).
Surface {
    id: root

    required property bool leftSide
    required property int order
    required property real margin
    // Largura da tela, para colar na borda direita.
    required property real areaWidth
    property bool present: true
    // Entrada e saída (0 → 1), animadas por enter() e leave().
    property real shown: 0
    readonly property real padding: ThemeManager.spacing.normal
    readonly property real travel: width + margin + 24
    default property alias content: body.data

    level: 0
    width: 400
    radius: ThemeManager.radius.large
    visible: present && shown > 0
    opacity: Math.min(1, shown)
    x: leftSide ? margin - (1 - shown) * travel : areaWidth - width - margin + (1 - shown) * travel

    function enter(): void {
        leaving.stop();
        shown = 0;
        entering.restart();
    }

    function leave(): void {
        entering.stop();
        leaving.restart();
    }

    SequentialAnimation {
        id: entering

        PauseAnimation { duration: root.order * 40 * ThemeManager.anim.scale }
        Anim { target: root; property: "shown"; to: 1; type: Anim.Spatial }
    }

    Anim {
        id: leaving

        target: root
        property: "shown"
        to: 0
        type: Anim.StandardAccel
    }

    Item {
        id: body

        x: root.padding
        y: root.padding
        width: root.width - root.padding * 2
        height: root.height - root.padding * 2
    }

import QtQuick

// View model do painel de controles da central: o brilho da tela em foco e
// os botões de ícone (luz noturna, não perturbe, não apagar a tela e
// configurações). O card de rede usa o WifiState e o BluetoothState.
Singleton {
    id: root

    // A tela em foco: a externa desse monitor, se tiver DDC; senão a integrada.
    readonly property var screenBrightness: Brightness.screens.find(s => s.id === Brightness.focusedId()) ?? null
    readonly property bool hasBrightness: screenBrightness !== null
    readonly property real brightness: screenBrightness?.value ?? 0

    function setBrightness(value: real): void {
        if (screenBrightness)
            Brightness.setScreen(screenBrightness.id, value);
    }

    // { id, icon, checked }. Sem o hyprsunset, sem a luz noturna; sem a
    // ociosidade do shell, sem o "não apagar a tela". Configurações só abre.
    readonly property var toggles: [
        ...(NightLight.available ? [{ id: "nightlight", icon: "nightlight", checked: NightSchedule.on }] : []),
        { id: "dnd", icon: Icons.bellSleep, checked: Config.doNotDisturb },
        ...(Config.idleEnabled ? [{ id: "awake", icon: "coffee", checked: Config.idleInhibit }] : []),
        { id: "settings", icon: Icons.settings, checked: false }
    ]

    function trigger(id: string): void {
        if (id === "nightlight")
            NightSchedule.setOn(!NightSchedule.on);
        else if (id === "dnd")
            Config.doNotDisturb = !Config.doNotDisturb;
        else if (id === "awake")
            Config.idleInhibit = !Config.idleInhibit;
        else if (id === "settings")
            Panels.open("settings");
    }
}

pragma Singleton

import QtQuick
import Quickshell
import qs.core.widgets
import qs.services

// View model do painel de som da central: saída e entrada (o dispositivo, o
// volume, o mudo e a lista para trocar) e o volume de cada app que está
// tocando.
Singleton {
    id: root

    readonly property bool available: Audio.available
    readonly property real volume: Audio.volume
    readonly property bool muted: Audio.muted
    readonly property string volumeIcon: Audio.muted || Audio.volume === 0 ? Icons.volumeOff : Audio.volume < 0.34 ? Icons.volumeLow : Audio.volume < 0.67 ? Icons.volumeMedium : Icons.volumeHigh
    readonly property string outputName: Audio.deviceName
    readonly property real micVolume: Audio.micVolume
    readonly property bool micMuted: Audio.micMuted
    readonly property bool hasMic: Audio.source !== null
    readonly property string micIcon: Audio.micMuted ? Icons.micOff : Icons.mic
    readonly property string inputName: Audio.nodeName(Audio.source)

    readonly property var outputs: Audio.sinks.map(n => ({ node: n, name: Audio.nodeName(n), current: n === Audio.sink }))
    readonly property var inputs: Audio.sources.map(n => ({ node: n, name: Audio.nodeName(n), current: n === Audio.source }))

    // Um por app tocando: { node, name, icon, image, volume, muted }; `image`
    // é o ícone do app no tema de ícones ("" se não houver).
    readonly property var streams: AudioStreams.list.map(s => Object.assign({ image: s.icon ? Quickshell.iconPath(s.icon, true) : "" }, s))

    // O painel aparece com algo a mostrar.
    readonly property bool any: available || hasMic || streams.length > 0

    function setVolume(v: real): void {
        Audio.setVolume(v);
    }

    function toggleMute(): void {
        Audio.toggleMute();
    }

    function setMicVolume(v: real): void {
        Audio.setMicVolume(v);
    }

    function toggleMicMute(): void {
        Audio.toggleMicMute();
    }

    function selectOutput(item: var): void {
        Audio.setDefaultSink(item.node);
    }

    function selectInput(item: var): void {
        Audio.setDefaultSource(item.node);
    }

    function setStreamVolume(item: var, v: real): void {
        AudioStreams.setVolume(item.node, v);
    }

    function toggleStreamMute(item: var): void {
        AudioStreams.toggleMute(item.node);
    }
}

pragma Singleton

import QtQuick
import Quickshell
import qs.core.config
import qs.core.format

import qs.services

// View model da energia da central (a bateria, o perfil de energia e a
// bateria dos dispositivos Bluetooth) e, até a barra lateral sair, da seção
// Tela dela.
Singleton {
    id: root

    // Bateria
    readonly property bool hasBattery: Battery.available
    readonly property real percentage: Battery.percentage
    readonly property bool charging: Battery.charging
    // Embaixo da porcentagem: carregada, carregando ou o tempo restante.
    readonly property string batteryNote: Battery.full ? "Carregada" : Battery.charging ? "Carregando" : Battery.timeRemaining > 0 ? Format.duration(Battery.timeRemaining) : ""

    // Perfil de energia: um botão por perfil, o de desempenho só se houver.
    readonly property bool profilesAvailable: Battery.profilesAvailable
    readonly property int profile: Battery.profile
    readonly property var profileButtons: [
        { value: 0, icon: Icons.eco },
        { value: 1, icon: Icons.balance },
        ...(Battery.hasPerformance ? [{ value: 2, icon: Icons.rocket }] : [])
    ]

    function setProfile(value: int): void {
        Battery.setProfile(value);
    }

    // Dispositivos Bluetooth conectados que informam a bateria.
    readonly property var devices: withBattery(Bluetooth.devices)

    function withBattery(list: var): var {
        return (list ?? []).filter(d => d.connected && d.batteryAvailable).map(d => ({ name: d.name || d.address, icon: Icons.forDevice(d.icon), battery: d.battery }));
    }

    // O painel aparece com algo a mostrar.
    readonly property bool any: hasBattery || profilesAvailable || devices.length > 0

    // Tela: uma entrada por tela com brilho ajustável (a integrada e os
    // monitores externos por DDC/CI).
    readonly property bool hasBrightness: Brightness.anyAvailable
    readonly property var brightnessScreens: Brightness.screens
    readonly property real brightness: Brightness.shownValue

    function setBrightness(id: string, v: real): void {
        Brightness.setScreen(id, v);
    }

    // "Não apagar a tela" (a ociosidade fica na feature idle; aqui só o botão).
    readonly property bool keepAwake: Config.idleInhibit
    readonly property bool idleEnabled: Config.idleEnabled

    function setKeepAwake(on: bool): void {
        Config.idleInhibit = on;
    }

    // Luz noturna: ligar ou desligar agora (até a próxima virada) e a temperatura.
    readonly property bool nightLightAvailable: NightLight.available
    readonly property bool nightLightOn: NightSchedule.on
    readonly property string nightLightStatus: NightSchedule.status
    readonly property int nightLightTemp: Config.nightLightTemp

    function setNightLight(on: bool): void {
        NightSchedule.setOn(on);
    }

    function setNightLightTemp(kelvin: int): void {
        Config.nightLightTemp = kelvin;
        NightSchedule.preview();
    }
}
